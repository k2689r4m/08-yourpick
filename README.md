## 프로젝트명
YourPick 부동산 거래 위험요소 분석 플랫폼

## 수행 시기
2023년

## 프로젝트 소개
부동산 거래 전 사용자가 입력한 매물정보를 기반으로 실거래가, 주변 시세, 건축물 정보, 부동산 등기정보 등 다양한 데이터를 종합하여 거래 위험요소를 분석하고 리포트 형태로 제공하는 서비스.

특히 전세 거래의 경우 매매가격 대비 전세가격, 실거래 및 주변 시세, 등기정보, 담보 관련 정보 등을 종합하여 위험요소를 점수화하고 사용자가 계약 전 참고할 수 있는 분석정보를 제공하도록 구현하였다.

서비스에 필요한 일부 부동산 관련 문서는 당시 직접 사용할 수 있는 공개 API가 없어 정부기관 웹사이트의 문서 발급 과정을 자동화하여 데이터를 확보하였다.

정부기관 사이트 접속부터 문서 조회 및 발급, 이미지 문자 인식, PDF 다운로드, PDF 데이터 가공, 내부 데이터 변환 및 위험도 분석까지 이어지는 데이터 수집·분석 파이프라인을 구축하였다.

Frontend, Backend, Database, 데이터 수집 자동화 및 분석 로직 전반을 단독으로 개발하였다.

## 정부기관 문서 데이터 수집 자동화

서비스에 필요한 일부 부동산 관련 문서는 당시 직접 활용 가능한 공개 API가 없어 웹 기반 문서 발급 과정을 자동화하였다.

전체 처리 흐름:

정부기관 웹사이트 접속  
→ 문서 조회  
→ 이미지 문자 인식  
→ 문서 발급  
→ PDF 다운로드  
→ PDF 데이터 추출 및 가공  
→ 내부 데이터 구조 변환  
→ DB 저장  
→ 부동산 위험요소 분석

### Selenium 기반 자동화
- Selenium WebDriver 기반 웹사이트 자동화
- 문서 조회 과정 자동 처리
- 필요한 부동산 문서 발급 과정 자동화
- 발급된 PDF 파일 다운로드
- Backend 분석 프로세스와 연계

## Python 이미지 문자 인식 모델

웹 기반 문서 발급 과정에서 발생하는 이미지 문자 입력 처리를 자동화하기 위해 Python 기반 이미지 문자 인식 모델을 적용하였다.

### Dataset 구축
- 실제 서비스 과정에서 필요한 이미지 데이터 직접 수집
- 학습용 이미지 Dataset 구성
- 학습 데이터 정리 및 전처리
- 프로젝트 환경에 맞는 문자 Vocabulary 구성

### Model Training
기존 OCR/CTC 계열 알고리즘 및 모델 구조를 프로젝트 목적에 맞게 적용하였다.

알고리즘 자체를 새롭게 연구·개발한 것은 아니며, 기존 방식을 활용하여 프로젝트에서 필요한 Dataset을 직접 구축하고 모델을 학습하였다.

- Python 기반 모델 학습
- 직접 구축한 Dataset을 이용한 Training
- 학습 모델 저장
- ONNX 기반 추론모델 활용

### Model Inference
- OpenCV 기반 입력 이미지 처리
- 이미지 크기 변환 및 전처리
- ONNX 모델 추론
- CTC Decoder 기반 문자 결과 변환
- Node.js 데이터 수집 프로세스와 연결

이를 통해 이미지 입력 → Python 모델 추론 → 문자 결과 반환 → 문서 발급 과정 진행으로 이어지는 자동화 흐름을 구성하였다.

## 프로젝트 내 역할
서비스의 Frontend, Backend, Database 및 데이터 수집·분석 시스템 전반을 단독으로 개발하였다.

사용자가 입력한 부동산 정보를 다양한 외부 데이터와 연결하고 실거래가, 호가, 주변시세, 건물정보 및 부동산 등기정보 등을 종합하여 위험요소를 분석하는 로직을 구현하였다.

특히 공개 API만으로 확보할 수 없었던 일부 부동산 관련 데이터를 처리하기 위해 웹 기반 문서 발급 과정을 자동화하였다.

문서 발급 과정에서 필요한 이미지 문자 인식을 위해 기존 OCR/CTC 계열 알고리즘을 적용하고, 프로젝트에 필요한 이미지 Dataset을 직접 수집·구축하여 모델을 학습하였다. 학습된 모델을 ONNX 기반 추론 프로세스로 구성하고 Node.js 및 Selenium 자동화 시스템과 연결하였다.

이를 통해 외부 문서 조회부터 PDF 확보, 데이터 가공, 내부 DB 저장, 위험요소 분석 및 사용자 리포트 생성까지 이어지는 전체 데이터 처리 파이프라인을 구축하였다.
